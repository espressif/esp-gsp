# Slider widget preview

This scene is the release-documentation example for `slider`. It includes two
horizontal ranges and one vertical range so pointer behavior, value ranges,
track thickness, and colors are visible in one compact preview.

```sh
tools/sim/run_scene.sh examples/widgets/slider/slider.json
python3 tools/sim/preview_wasm.py examples/widgets/slider/slider.json --title Slider
```
