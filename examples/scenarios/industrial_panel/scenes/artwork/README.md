# AXIS equipment artwork

`cell-studio.png` is an illustrative robotic assembly cell generated with the
built-in image generation tool. It is a design visualization, not a validated
CAD model of a particular machine.

The prepared 540×360 transparent PNG has RGB565-dithered color channels.
It is restored from the verified example asset archive for component users.
The bitmap is static; telemetry labels and controls remain native components.


`pneumatic-detail.svg` is a retained, illustrative circuit drawing using the same
restrained green/graphite palette as the native instrument panels. It has no
ambient sweep or baked animation frames. Process, Service and History share the
overview's 352-pixel instrument column; pressure values and traces remain bound
to the shared simulated telemetry.
