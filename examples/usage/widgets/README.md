# Widget examples

Each directory contains a focused scene named after its GSPC widget. These are
small authoring examples rather than independent ESP-IDF projects. Additional
scenes in a directory demonstrate related capabilities such as vector motion.


Use [hello_world](../hello_world/README.md) for display startup and generated C
API integration, [effects](../effects/README.md) for animated materials, or the
[component reference](../../../docs/en/components/index.md) for field semantics.
