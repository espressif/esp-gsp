# 基本操作

本文介绍 ESP-GSP Studio 中的常用编辑工作流。

## 创建场景

1. 点击场景标签栏的 **+** 按钮，或使用菜单 **文件 → 新建场景**。
2. 输入文件名。新场景默认保存在 `scenes/` 目录。
3. 在右侧 **样式 → 场景设置** 面板中设置场景尺寸和背景。

场景是普通的 JSON 文件。编辑器直接写入；不涉及中间工程格式。

## 添加控件

- 从控件面板拖动控件到画布上。
- 或右键点击画布/对象树，从上下文菜单中选择 **添加**。

控件放置在拖放位置。使用右侧属性面板微调位置（`x`、`y`）、尺寸（`w`、`h`）和
所有类型特定字段。

## 选择与变换

- **点击** 选择单个控件。
- **Ctrl+点击** 或框选进行多选。
- 拖动选择手柄调整大小。
- 拖动控件主体重新定位。
- 使用左侧 **对象树** 浏览层级结构、重新排序兄弟节点或更改父级关系。

## 编辑属性

右侧面板显示选中控件的所有可编辑字段，按类别分组。

- **名称** — 为应用需要在运行时访问的元素设置稳定的 `name`。
  编译器根据此名称生成类型化的 C 辅助函数。
- **回调** — 为需要传达到应用的操作设置 `callback`。
- **样式 / 主题** — 样式编辑创建本地覆盖。清除样式覆盖会恢复继承值。

所有属性更改会立即反映在 WASM 预览中。

## 管理资源

- **引用已有文件** — 点击资源字段旁的 **↗** 图标，引用磁盘上已有的文件，
  包括工程外的文件。
- **导入副本** — 点击 **+** 将文件复制到工程的 `assets/` 目录中。
  导入前会经过编译器验证。
- **替换** — 替换图片保留现有布局尺寸。
  使用显式的适配源文件操作来从新文件更新尺寸。

支持的资源类型包括位图（JPEG、PNG）、SVG、位图动画、字体（TTF/OTF）和
视频文件（MP4、AVI、MOV、WebM — 编译时需要 FFmpeg）。

## 场景设置

打开右侧 **样式 → 场景设置** 面板：

- **尺寸**（`w`、`h`）和 **背景**（`screen_bg`）。
- **滑动策略** 和 **默认字体 / 字号**。
- **高级设置**（默认折叠）：额外字符集、UTF-8 语料文件、字体字节预算和
  顶层动作。

工程默认值仅在创建新场景时生效；控件的显式字体设置优先于场景默认值。

## 撤销与重做

每个场景有独立的撤销栈。使用 **Ctrl+Z** / **Ctrl+Shift+Z**（macOS 上使用
**Cmd**）进行撤销和重做。干净的场景变更进入撤销历史。与本地编辑冲突的外部
变更会暂停自动保存并显示两个版本。

## 预览与仿真

- 画布在每次编辑后提供实时 WASM 预览。
- 按 **F5** 或使用菜单 **仿真** 打开带动画播放的完整交互式模拟器。
- 对于无窗口或 CI 预览，使用独立模拟器，参见
  [模拟器预览与测试](../configuration/simulator-preview.md)。

## 导出

打开 **导出** 面板，有三种交付路径：

1. **ESP-IDF 集成** — 继续在现有 ESP-IDF 应用中使用。
   生成的交互 API 和 C 头文件由所属 CMake 构建产生。
2. **独立 UI 目录** — 可重新构建的目录，包含场景输入、匹配的编译器、
   许可证和 `rebuild.cjs` 脚本。在记录的 OS/架构上使用 Node.js 22+ 运行。
3. **预编译包** — 针对选定固件上下文的可部署 Bundle。清单记录工具链、
   运行时契约、Profile、容量和场景顺序。

编译结果保持可见且包含文件管理器入口。最近一次导出结果按工程保存。

## 键盘快捷键

| 操作 | 快捷键 |
|---|---|
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Shift+Z |
| 保存 | Ctrl+S |
| 仿真 | F5 |
| 删除选中 | Delete |

## 提示

- **自动保存** 在最后一次编辑后 500 ms 触发。指针手势（拖动、调整大小）在
  手势结束时保存。
- **文件监视** 在 250 ms 后协调外部变更，有 5 秒轮询后备和窗口聚焦时协调。
- 删除 `.gsp-editor/` 目录不影响源文件。工程可以在没有编辑器元数据的情况下
  重新打开。
