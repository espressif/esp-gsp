# 介绍

ESP-GSP 是面向 ESP-IDF 的预编译 UI 工具链与有界图形运行时，适用于需要可评审界面源码、确定性资源、稳定应用接口，并由 BSP 掌控显示链路的产品。

## 提供的能力

| 能力 | 职责 |
|---|---|
| 声明式场景 | JSON 负责层级、布局、样式、静态资源和局部动作。 |
| 编译式 Bundle | GSPC 校验输入，将场景与资源打包为带版本的 GSPB 数据。 |
| 类型化集成 | 稳定名称产生 setter、getter、事件判断和组件适配接口。 |
| 可移植渲染 | 同一核心通过 WebAssembly 在本地预览，通过 ESP-LCD 在设备渲染。 |

## 职责边界

| 内容 | 负责层 |
|---|---|
| 结构、外观、静态资源 | 场景 JSON |
| 校验、资源转换、Bundle/API 生成 | GSPC |
| 产品状态、网络、存储、传感器 | 应用任务 |
| 屏幕时序、旋转、缓冲区、触控映射 | BSP 与 ESP-LCD 显示目标 |
| 渲染、输入分发、组件状态 | ESP-GSP 运行时 |

UI 回调向应用任务发出请求；应用完成状态变更后，通过生成 setter 更新界面。

## 选择数据接口

- 相机、视频等持续更新的像素使用 Canvas。
- PNG、JPEG 等编码图片的替换使用运行时图片 API。
- 大型数据集合使用 List、Grid、Wheel 或 Message List，通过可见项复用控制内存。
- 网络、存储、认证和业务状态由应用任务处理。
